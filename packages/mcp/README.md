# @plugload/mcp

Plugload's safe content-operations adapter for Payload CMS's official MCP plugin. It adds explicit schema allowlists, previews, independently authenticated approvals, idempotent apply, and hash-chained audit events without replacing Payload MCP or bypassing Payload access control.

See [Plugload](https://github.com/owwix/plugload) for setup, compatibility, security guidance, and the Apache-2.0 license.
